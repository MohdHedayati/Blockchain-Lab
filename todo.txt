Experiment 1
Represent
elements of a finite field  (F_p),
where (p) is a prime number, using a Python class.


1.
Create a Python class named `FieldElement` to
represent a finite field element. Store `num` and `prime` as attributes.


2.
Check that `num` lies between 0 and `prime - 1`, inclusive. If it does not,
raise a `ValueError`.


3.
Implement the equality method to check whether two `FieldElement`
objects are equal. Two objects are equal only if both their `num` and `prime`
attributes match.


4.
Implement addition, subtraction and multiplication operations for `FieldElement`
objects, ensuring that the results remain valid elements of the same finite
field.


5.
Test the implementation with suitable inputs and demonstrate the arithmetic
operations, equality checking and handling of an invalid element.


Submission:
Submit
the Python code along with sample inputs and outputs.
